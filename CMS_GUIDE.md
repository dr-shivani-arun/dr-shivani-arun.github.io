# CMS User Guide — For Non-Technical Users

This guide explains how to add and edit content on the Dr. Shivani Arun website using the Decap CMS admin panel. No coding knowledge is required.

## Accessing the CMS

1. Go to: `https://dr-shivani-arun.github.io/admin/`
2. You will be prompted to log in with your GitHub account.
3. After logging in, you'll see the **Content Manager** dashboard.

## Adding a New Health Education Module

1. In the left sidebar, click **Health Education**.
2. Click the **New Health Education** button (top right).
3. Fill in the fields:

| Field | What to enter | Required? |
|-------|--------------|-----------|
| **Title** | The name of your module/course/resource | ✅ Yes |
| **Description** | A short summary (2-3 sentences) | ✅ Yes |
| **Date** | The publication or creation date | ✅ Yes |
| **Category** | Choose from: Oral Health, Digital Health Literacy, NCD Prevention, Community Health, Mental Health, Health Policy | ✅ Yes |
| **Format** | Choose from: article, video, interactive, course, webinar | ✅ Yes |
| **Duration** | e.g. "4 hours", "2.5 hours" | ❌ No |
| **Difficulty** | Beginner, Intermediate, or Advanced | ❌ No |
| **Target Audience** | e.g. "Community Health Workers, ASHA workers" | ❌ No |
| **Cover Image** | Upload an image (optional — a default placeholder will be used if left blank) | ❌ No |
| **Module URL** | Link to the full module (if hosted externally) | ❌ No |

4. Click **Save** (or **Save & Publish** to make it live immediately).

## Adding a New Research Entry

1. In the left sidebar, click **Research / Projects**.
2. Click the **New Research** button.
3. Fill in the fields:

| Field | What to enter | Required? |
|-------|--------------|-----------|
| **Title** | The title of your paper or project | ✅ Yes |
| **Authors** | List of author names (one per line) | ✅ Yes |
| **Venue** | Journal, conference, or institution name | ❌ No |
| **Date** | Publication or project date | ✅ Yes |
| **Category** | Choose from: Oral-Systemic Link, Health Literacy, Epidemiology, IISc Project, MOOC Development, Community Health | ✅ Yes |
| **Abstract** | A brief summary of the work | ❌ No |
| **Cover Image** | Upload an image (optional) | ❌ No |
| **Paper URL** | Link to the published paper | ❌ No |
| **PDF Link** | Link to the PDF file | ❌ No |

4. Click **Save** (or **Save & Publish**).

## Tips

- **Drafts**: Items saved as "Draft" won't appear on the live website. Use "Publish" to make them visible.
- **Editing**: Click on any existing entry to edit it.
- **Images**: Recommended size is 800×500 pixels. Supported formats: JPG, PNG, SVG.
- **Preview**: After publishing, the website will update automatically within a few minutes (GitHub Pages rebuilds on each push).
